Cell Block Zero

A prison break in the shape of the first Wolfenstein 3D, written in Lua for LÖVE 11.x. No asset files at all: every wall texture is written pixel by pixel at startup, every sprite and every first person weapon is drawn into a canvas, and every sound is synthesised. Three blocks, drawn in text files.

Code on GitHub Read me The long manual

The wing

Lights out an hour ago, and the guard who let himself into your cell was not there to talk. He is on the floor now, and everything you own came off him: a hatchet, a revolver and a vest, torn and half as good as it was. The sun comes up in a few hours.

Quiet work

Nobody has to die loudly. A shot is heard only in the room it was fired in, so one careless round costs you that room and not the block.

When it goes wrong

And it will. Rockets and grenades carry through the whole wing: everybody hears those.

Getting out

Keys are never lying on the floor. Each one is on a guard, in a locker or behind a section of wall that slides back.

What is in it

Nothing on disk

No images, no sound files. Textures are written pixel by pixel, sprites are drawn into a canvas, sounds are synthesised at startup.

Guards with a brain

Vision cones, line of sight, patrol rounds, cover, flanking, grenades. They answer a noise in twos and threes, never as a block.

Levels in text files

One character per tile. Walls, doors, guards, dogs, scenery, lockers, panels and where each key hides.

Silent options

Throat, hatchet or neck on anyone who has not seen you, a throwing knife, a silencer, and leg traps for the dogs.

Prisoners

Let one out and he goes after the guards himself. He is easy to kill and he takes somebody with him.

A console

F2 opens it: spawn guards or dogs, drop a sleeping sergeant, give yourself anything, or load the shooting range.

Running it

On Linux or macOS, with LÖVE 11.x installed:

git clone https://github.com/sfeSantos/cell-block-zero.git
love cell-block-zero

On Windows:

  1. Install LÖVE 11.5 from love2d.org, the 64 bit installer. Lua itself is not needed: LÖVE carries its own.
  2. Clone or download the repository to a folder, say C:\Users\you\CellBlockZero.
  3. Drag that folder onto love.exe, or run it from a command prompt:
"C:\Program Files\LOVE\love.exe" C:\Users\you\CellBlockZero

For a single file to double click, zip the contents of the folder, not the folder itself, and rename the zip to cellblockzero.love.
