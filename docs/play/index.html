Cell Block Zero

LÖVE 11.4 built for WebAssembly. The game is the same .love file the desktop runs, about 340 KB, and the engine around it is 5 MB.

CELL BLOCK ZERO

A dead guard on your cell floor, and until sunrise to be gone. Sound and the mouse both need a click to start, so the block waits here until you ask for it.

Click the picture to take the mouse. Escape gives it back and holds the block at the menu.

Keys

W and S, A and D
walk, and step sideways
the mouse
look around, left button fires, ctrl does the same
shift
run
space
doors, lockers, wall panels, prisoners, the way out
1 to 7
hatchet, revolver, uzi, launcher, grenade, flash, knife
G, F, V, B
throw a grenade, a flash, a knife, set a trap
R
reload, and firing on empty does it for you
T
silencer on and off, middle mouse button does it too
tab
the map
P, escape
pause, and the menu with Carry on to come back
F1
the full list of controls
F9
save, and the menu loads it back

The browser keeps the save and the settings in its own storage for this page, so they survive a reload but do not follow you to another browser, and clearing site data for github.io clears them. The window is fixed here, where the desktop build opens on the whole screen: the code and LÖVE will do that.
